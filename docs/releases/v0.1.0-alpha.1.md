# Code Ark v0.1.0-alpha.1 · 代码方舟源码预览

代码方舟（Code Ark）是面向本地开发的 Docker 环境工作箱。本次发布提供可下载、可校验的源码快照，包含17套Compose配置、1份宿主机工具指南，以及Tauri桌面工作箱源码。**这是源码预览，不包含桌面安装包。**

English Summary: This prerelease distributes a checksummed source snapshot with 17 Docker Compose configurations and the Code Ark desktop source preview. It does not include a desktop installer. Docker is installed separately; Compose presets can be used without building the desktop app.

[发布与下载](https://github.com/StephenQiu30/code-ark/releases/tag/v0.1.0-alpha.1) · [快速开始](../../README.md#快速开始) · [English](../../README.en.md) · [FAQ](../faq.md)

## 如何使用

直接使用Compose，不需要Node、Rust或桌面应用：

```sh
git clone --branch v0.1.0-alpha.1 --depth 1 https://github.com/StephenQiu30/code-ark.git
cd code-ark/services/redis-start-local
docker compose up -d
docker compose exec redis redis-cli ping
```

预期输出为`PONG`，默认宿主入口`127.0.0.1:6379`。本机已占用该端口时，先按服务说明调整映射；本次不承诺所有人的6379均空闲。完整服务表、前置依赖与数据说明见[服务索引](../../services/README.md)。

下载源码归档后，使用同页的`SHA256SUMS`校验文件；`source-manifest.json`记录源提交和归档摘要。macOS可用`shasum -a 256 -c SHA256SUMS`，Linux可用`sha256sum -c SHA256SUMS`。源码归档来自Git跟踪文件，不包含维护者的.env、工作区数据、缓存、原始日志或已编译依赖。

桌面源码的工具链、构建及操作范围见[toolbox/README.md](../../toolbox/README.md)。浏览器开发服务器不提供Tauri原生后端，不能代替桌面入口。

## 实际验证与边界

截至2026-11-13，macOS Apple Silicon（arm64）源码运行中，16个预设完成两轮真实启动、协议检查及保留数据停止；Nacos、RocketMQ、Canal、Temporal另有清除启动缓存后的后台新鲜观察。详细证据见[08](../research/08-桌面全局消息与预设启动验证.md)和[09](../research/09-其余预设真实启动验证.md)。

完整Elastic栈因现场可用内存小于6GiB被预检拒绝，未创建容器；这不是完整栈通过。AMD64三份镜像归档、其他原生桌面目标、所有场景/业务功能、故障矩阵及最终安装包仍待独立验收。源码运行证据不等于本次归档已通过桌面安装验收。

本次没有桌面安装器，因此不提供应用签名、公证或自动更新承诺。公开桌面包继续遵循项目既有发行门禁；本次源码预览不绕过它。
