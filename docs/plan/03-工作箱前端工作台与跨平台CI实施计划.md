唯一来源：[03 工作箱可视化工作台与新手引导 PRD](../prd/03-工作箱可视化工作台与新手引导PRD.md)。本 Plan 只属于该 PRD；UI 双栏布局、四标签抽屉详情、双层脱敏策略与 `MediaCrawler` 宿主机指引规格沿来源 PRD 指向的 [设计 03](../design/03-工作箱界面交互与新手引导设计.md) 读取。当前状态：**未执行**。

## 1. 目标、架构与约束

- **目标**：完成脱敏诊断报告与 Tauri IPC 接口层（`diagnostics.rs`、`commands.rs`），构建借鉴 `mac-gaming-toolbox` 的 React 19 + TypeScript + Tailwind CSS 双栏桌面工作台，验证组件交互与安全防呆，并建立覆盖 macOS / Windows / Linux 的自动化 CI 与临时工作区端到端冒烟验证。
- **全局约束**：
  - 所有 `.env` 密钥存储与 Docker 操作留存在 Rust 核心层，前端仅消费 IPC 视图状态（密码默认以 `••••••` 掩码渲染，不落盘 `localStorage`）；
  - 诊断导出器必须对配置键值与运行容器日志正文中的全部非空密钥执行双层脱敏（`***REDACTED***`）；
  - **Review Focus（重点守护用例）**：
    - **重叠密钥与空值脱敏边界**：同时存在互为子串的多个秘密值及空值字段时，长秘密优先替换且不损坏报告正文或空值占位；
    - **默认掩码与宿主机/容器代码片段隔离**：宿主机代码片段清晰展示 `127.0.0.1`，容器内部片段使用服务名并带禁止写 `localhost` 警示；
    - **重置弹窗精准警告与字符匹配确认**：输入目标服务 ID 完全匹配前确认按钮禁用，并针对 `temporal`/`xxjob`/`seata` 与 `mysql`/`pgsql` 显示不同范围提示；
    - **卡片点击不误启动容器**：选中场景/服务卡片先展开查看，仅点击显式操作按钮触发启停。
