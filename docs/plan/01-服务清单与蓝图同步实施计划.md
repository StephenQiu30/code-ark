# 01 服务清单与蓝图同步实施计划

唯一来源：[01 Code Ark 工作箱底座与蓝图管理 PRD](../prd/01-CodeArk工作箱底座与蓝图管理PRD.md)。本 Plan 只属于该 PRD；架构分层、`.blueprint-manifest.json` 规则与覆盖层协议沿来源 PRD 指向的 [设计 01](../design/01-CodeArk工作箱顶层架构与蓝图同步设计.md) 读取。当前状态：**未执行**（本地缺少 `rustc` / `cargo`，仅可运行 Node.js 同步校验脚本）。

## 1. 目标、架构与约束

- **目标**：搭建 `toolbox/` 源码目录，建立构建期 SSOT 蓝图提取与校验流水线（17 套 Compose + 1 份 `mediacrawler` 补丁指南 + 7 个场景预设），初始化 Tauri `2.12.5` + Rust 底座，并落地配置目录加载（`catalog.rs`）、无损 `.env` 引擎（`env_store.rs`）与非破坏性蓝图物化/覆盖层引擎（`blueprint.rs`）。
- **全局约束**：
  - 根目录 `*-start-local`、`*-start-lcoal` 与根 `README*.md` 保持 **0 修改**；
  - 蓝图同步产物严格排除 `.env`、`*-data/`、`data/`、`logs/`、`.DS_Store` 及宿主机 `start.sh`/`stop.sh`/`uninstall.sh`；
  - 容器挂载 `.sh` 文件（如 `temporal/scripts/*.sh`）无论在同步期还是运行物化期一律按 `\n`（LF）写入字节；
  - 所有覆盖层端口改动使用 Compose v2.20+ `ports: !override`，`-p <canonical_project>` 锁定与根仓库兼容的网络和命名卷前缀；
  - **Review Focus（重点守护用例）**：
    - **脏 `.env` 合并边界**：含中文注释、空行、CRLF、值内含 `=`（例如 `NACOS_AUTH_TOKEN=abc==`）且无末尾换行时，保留原密码、注释与键顺序，只补全缺失项或替换占位符；
    - **Canal / SearXNG / Kibana / Nacos 密钥合规**：`CANAL_MYSQL_PASSWORD` 长度严格 `<= 32` 字符；`NACOS_AUTH_TOKEN` Base64 解码 `>= 32` 字节；`SEARXNG_SECRET` 为 64 位小写 hex；
    - **覆盖层联动副作用**：改 `kafka` 端口同步更新 `KAFKA_ADVERTISED_LISTENERS`；改 `monitoring` 端口同步更新 `GF_SERVER_ROOT_URL`；`seata`/`xxjob` 联动 `mysql-start-lcoal_default`；`rocketmq` 写出 `conf/broker.toolbox.conf`。
