唯一来源：[PRD 01](../prd/01-CodeArk工作箱底座与蓝图管理PRD.md)。技术规格沿该PRD唯一design读取。状态：**全部任务未执行**（2026-11-12）；既有审查的只读Compose校验不计为本计划通过。

**目标**：构建17/1/7目录与纯净内嵌资源，生成独立实例、无损有效配置、可复现镜像覆盖和升级候选。

**技术栈**：Tauri `2.12.5`、tauri-build `2.7.4`、npm CLI/API `2.12.4`、Rust、TypeScript/React、Compose `>=2.24.4`。版本是锁定起点，实施先验证兼容并提交Cargo/pnpm锁文件；其他插件不以浮动`2`代替完整锁。

## 1. 全局约束

- 根17服务Compose、配置、`.env.example`和数据目录不修改；未来只补根`.gitattributes`的Shell LF规则及必要文档/忽略项。
- 仅复制版本控制下白名单运行资产，禁止秘密、数据、日志、备份和越界symlink；全部bind/build引用在资源包闭合。
- `sourceProject`只作识别；运行容器/项目/网络/卷全按实例标识，Nacos固定卷名必须覆盖；已有依赖优先显式复用。
- 唯一插值输入与完整override，最低Compose2.24.4和能力验证；不能用向XXL容器追加MYSQL_HOST代替最终PARAMS。
- `.env`已有值/用户手改文件不静默覆盖；新建实例逐字段秘密策略；字面特殊字符、中文路径及权限要覆盖。
- 验证无真实秘密输出；生成运行候选包含秘密时权限受限，config输出只在后端解析且脱敏。

## 2. Review Focus

1. 同名卷/旧CLI/两个工作区不能因临时路径而被误当隔离：任务2及真实联调断言资源ID、旧数据不变。
2. `$/#/=/引号`及无末尾换行的密码经dotenv/YAML往返不变：任务3/4断言最终JDBC及秘密原值。
3. 新Nacos/Kibana公开样例需替换，已有实例相同字符串不能被误轮换：任务3区分新旧实例。
4. override端口合并不能保留原发布端口或破坏UDP、Nacos偏移、Kafka内部监听：任务4检查最终模型。
5. 手改蓝图/不兼容升级/带symlink路径不能被“有备份”绕过：任务5拒绝自动覆盖/降级/越界。

| `toolbox/tests/fixtures/blueprints/`、`env/`、`updates/` | 合成秘密、来源回归模板、旧版本/手改/越界fixture；不复制用户运行数据 |

`SecretValues`为后端临时内存映射，禁止序列化到IPC；`EnvCandidate { document, changed_keys, validation_errors }`为私有待提交值；`OverrideArtifact { override_path, env_path, config_digest }`含受限文件位置，不含对外明文。`BlueprintUpdatePlan { unchanged, safe_updates, conflicts, compatibility_gate }`及`MaterializeResult { manifest, created_paths, conflicts }`用于预览/应用，不能自行批准冲突。

共享类型字段按design定义，TS由ts-rs生成且用真实serde夹具回归；后续Plan不能另造同名类型。`verify-blueprints.mjs --mode development`只检查资产/schema并报告制品未解析项，用于任务1骨架，不能产出发行安装包或允许运行未解析镜像。`--mode candidate --target <target_id>`要求registry digest或归档SHA/image ID、插件校验和及架构清单/完整资产，实机证据可pending；常规打包默认candidate。`--mode release --target <target_id> --evidence <acceptance.json>`额外匹配包外证据与源/锁/候选SHA。任务6的producer独立于桌面安装包先产出制品，避免任务1先要求尚未生成归档的循环。
