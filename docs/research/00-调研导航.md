# 调研导航

本目录保存对标产品分析、Tauri 版本与跨平台技术选型调研、Code Ark 仓库现状盘点及设计完整性审查。**调研和审查报告本身不是技术合同**，仅作为决策依据；采纳后的规则写入 [设计目录](../design/00-设计导航.md) 才对实施生效。

## 证据等级标记

| 标记 | 含义 | 适用范围 |
| --- | --- | --- |
| `S` | 源码或仓库制品直接核验 | 对标仓库 GitHub 文件、本仓库真实 `docker-compose.yml`/`.env.example`/`README.md` |
| `O` | 在线发布记录与工具命令实测 | GitHub Releases API、`npm view`、联网检索结果、`docker ps` 现场观察 |
| `I` | 基于事实推导的设计建议 | 迁移到 Code Ark 工作箱时的适配取舍与风险提醒 |
