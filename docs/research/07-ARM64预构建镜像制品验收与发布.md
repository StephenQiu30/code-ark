# ARM64 预构建镜像制品验收与发布

English Summary: Three prebuilt Linux ARM64 service image archives passed isolated native functional checks. This record covers image artifacts and their public source/license material. Desktop orchestration, installers and AMD64 acceptance are separate.

## 静态及原生功能验证

本机为 macOS ARM64，Docker `desktop-linux` daemon 为 Linux aarch64、约 12 GiB。已有其他项目使用 daemon；测试仅运行独立 Compose 项目 `codeark-artifact-arm64-20261113`，容器和卷标记 `codeark.task=artifact-arm64-20261113`。三个阶段顺序执行，不启停既有容器、不读取既有数据库、不更改服务目录中的 `.env`。

| 验证 | 实际结果 |
| --- | --- |
| Compose 静态配置 | 隔离验收配置的 `docker compose config --quiet` 通过 |
| 归档完整性 | 三份归档 SHA256 全匹配；OCI 每个 blob 重新计算 SHA256；索引 ID、内容标签和镜像 `linux/arm64` 一致 |
| MinIO，API `127.0.0.1:24900` | 512 MiB 限额；ready API、SigV4 建桶、对象 PUT/GET、重启及 `--force-recreate` 后相同内容读回通过 |
| XXL-Job，`127.0.0.1:24881/xxl-job-admin` | 临时专用 MySQL 限 768 MiB、Admin 限 512 MiB；使用对应源码 SQL（utf8mb4）初始化，真实登录、认证 `jobgroup/pageList` 读取两条数据库记录通过；修改测试标记后，MySQL 重启和 Admin 重建后均保留 |

IK 文本“中华人民共和国国歌”返回 10 个 token，包含“中华人民共和国”“人民”“共和国”“国歌”；重建后结果一致。此验证通过真实 `_analyze`，不是首页 HTTP 200 替代。

所有测试容器在对应阶段结束后停止并移除；专用命名卷保留，没有执行全局清理或删除用户既有数据。上述端口仅用于临时验收，交付结束时不保留运行入口。

## 下载校验与范围限制

发行后对六个公开附件执行不带认证头的完整下载（`curl -q`，未传认证参数/头），全部通过本地 SHA256 校验；三份镜像、资料包、公开清单与 SHA256SUMS 文件本身逐一匹配，GitHub 返回的附件 digest 也与本地一致。真实公开 URL 为发行页 `/releases/download/images-2026.11.13-arm64/<附件名>`，没有使用 API 的登录下载替代匿名下载。
