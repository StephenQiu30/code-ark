## design → prd → plan 映射规则

- 技术合同、字段结构、状态机与安全约束全部在 `design` 维护；
- 用户行为、范围边界与可测验收条件在唯一对应的 `prd` 维护；
- 实施拆解、测试 assertions 与验证命令在 `prd` 下属的 `plan` 维护。
